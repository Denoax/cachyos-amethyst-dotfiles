The website and non-banner showcase media have been retired. The existing GIF, animated WebP, MP4 and PNG are preserved byte for byte under `assets/banner/`, independent of Pages. They show the existing wallpaper's complete natural ten-second forward period with the original tonal blend and AMETHYST wordmark. The original master composition used a native 3840×1280 crop; the retained public MP4/poster are 1800×600, the GIF is 792×264, and the WebP is 1152×384. Raw wallpaper, native capture masters and private process records remain excluded.

No generated imagery, new capture, re-encoding, reversal or interpolation was introduced during retirement. GIF/WebP encoding cadence is not a physical-display performance measurement. Attribution grants no new license to third-party media. Earlier presentation code and its notices remain recoverable through Git history.
