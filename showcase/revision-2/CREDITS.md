# Showcase sources and rights

The desktop and application footage was recorded on the user's current workstation. The sample programs, site, captions, helper changes and original documentation are project work. Installed application UI, fonts, package icons and store content retain their upstream rights. No extension, font or application binaries are bundled.

The animated background is the user's existing [DesktopHut “Black and White Look”](https://www.desktophut.com/black-and-white-look-live-wallpaper). Its raw video remains local. No open redistribution license was established; the project code license grants no permission to extract or reuse its artwork. These deliverables contain only requested documentary desktop captures and optimized derivatives. A fresh installation uses the separately documented project-owned plain fallback, not this video.

[Hyprland](https://hypr.land/), [Caelestia](https://github.com/caelestia-dots/shell) and [Quickshell](https://quickshell.org/) supply the underlying desktop. Microsoft VS Code is the official installed editor; `beem.monochromator` 0.36.1 supplies Monochromator Dark Amethyst. Current source theme extraction gives primary `#d559ff`, with the existing `#ac79c4` border and `#9361ad` focus treatment. The theme source SHA-256 is `f7711d1472136e3d634c8bdf23b288ea4254bc24967ce400052b39a32078ae41`. Presentation opacity is 0.78 on the isolated VS Code, Dolphin and Discover windows, focused and unfocused.

The dashboard shows existing media metadata as part of the real UI. No soundtrack was captured, and existing playback was not controlled. A live visualizer is a UI demonstration, not proof of an audio device or microphone test.
