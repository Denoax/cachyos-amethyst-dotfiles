# Amethyst showcase

React, R3F, Three.js and Motion use the lockfile from the pinned portfolio foundation. Node 22.12+ (or Node 20.19+) is required by Vite 7.

```sh
npm ci --ignore-scripts
npm run dev
```

Open the URL printed by Vite. `npm run build` includes TypeScript checking. `npm run preview` serves the built site.

One WebGL canvas owns ASCII, fragments, the actual video texture, glass flights, pointer response and footer points. DOM owns navigation, range inputs, playback controls, code and links. The shared video owner permits one decoder, explicit playback under reduced motion, and an ordinary poster/error route. All videos are muted.

The site changes no desktop settings. The installer and its validation remain separate. Read [credits](../docs/ASSETS.md) and [current support limits](../docs/VERIFICATION.md).
