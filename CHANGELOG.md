# Changelog

## v0.1.0-alpha.1

Initial allowlisted export of the source CachyOS desktop, exact Amethyst palette and CP workspace. Adds a separately scoped chezmoi renderer, file-transaction installer, recovery tests, package/source manifests, GPL patch provenance, actual source-desktop capture tooling and selected documentary media.

Fresh CachyOS installation, first login, physical laptop acceptance and continuous human media review are release blockers. This is a prerelease, with detailed per-flow evidence rather than a stable-support claim.
