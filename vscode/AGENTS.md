# VS Code scope

Read `SPEC.md`. Preserve the user's current editor instances, profiles, extensions and active Codex sessions. Verify whether official Microsoft VS Code is actually installed before describing it as such. Inspect executable/package identity rather than assuming the `code` command identifies the intended product.

Export declarative settings, snippets, tasks and extension identifiers. Never copy storage databases, accounts, tokens, machine IDs or work histories. Test an imported profile in a separate temporary user-data/extensions directory before any live change. Do not copy Code OSS private data wholesale into Microsoft Code.
