# Contributing

Read the project-local AGENTS and scoped instructions before editing. Work in disposable homes; never exercise installer recovery against a production home. Preserve the exact owned-file boundary, upstream licenses and private-data exclusions.

Run `python3 tools/check`, the installer unittest suite with a real chezmoi binary in `CHEZMOI`, and the CP runner regression suite with the required tools available. Recheck Hyprland with its installed `--verify-config` interface after Lua edits. Update compatibility records when the package tuple changes.

Use actual desktop evidence for feature claims. Keep raw logs, master recordings, local wallpapers and backups outside Git. Describe unrun checks explicitly. Stable releases require fresh-session/daily-use acceptance. The README banner links to the Pages showcase. Keep public presentation assets and native validation evidence scoped separately.
